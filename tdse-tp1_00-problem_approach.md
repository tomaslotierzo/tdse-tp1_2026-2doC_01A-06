COMA Electronics propone una solución para un sistema de aparcamiento automatizado. Primero dispone de sensores o cámaras que detectan si hay un auto en el terminal seguido de una primera máquina, que al presionar un botón, imprime un boleto con un numero de usuario, fecha y hora de ingreso y se abre la barrera para acceder al estacionamiento y el usuario estaciona su auto. Al salir, hay otra máquina que escanea el boleto de entrada y procesa el pago según la duración del estacionamiento, y devuelve un ticket que valida el pago. Después vuelve a la terminal, donde hay una última máquina que lee el ticket de pago y abre la barrera para que el auto salga.

La implementación de Parking Ticket Dispenser Machine (Entry) sigue el proceso general de escrutinio, proceso y actuación. Cuando el coche llega a la terminal, la cámara lo detecta y la pantalla de la maquina le da la bienvenida al usuario. Si se presiona el botón se imprime el ticket y se abre la barrera para permitir el paso del auto. Si la bobina que actúa como sensor detecta que el auto se va, se cierra la barrera y se le envía al servidor el registro del auto correspondiente.

Los modelos de comportamiento para los módulos de código C siguen un bucle principal que se repite cada 1 milisegundo (para la ejecución cíclica de tareas no bloqueantes). En cada iteración primero chequea los N sensores por si alguno esta activado, en este caso, si los pulsadores o los switches están activados, de ser así, pone un mensaje en la System Interface. Después chequea en el System si hay algún mensaje nuevo, cargándolos desde la System Interface, si hay uno nuevo, pone un mensaje en la Actuator Interface. Por último, revisa los N actuadores, si se detecta un nuevo mensaje en la System Interface, se ejecuta la acción en el actuador correspondiente, y finaliza esta iteración.
